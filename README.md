# Selected Economics Projects

**Eva Macchitella — MSc Economics, HEC Lausanne**

This repository contains four PDF reports from my Master's studies.

### Master's Thesis
**MSc_Economics_Thesis_EM.pdf**

*Household Portfolio Composition and Heterogeneous Monetary Policy Transmission in the Euro Area.*

Examines how household liquidity, housing and equity exposure shape consumption responses to monetary policy. Combines ECB HFCS microdata from ten euro-area countries, local projections in R and a four-agent New Keynesian model in Dynare.

### Dynare Project
**Dynare_project_Macchitella.pdf**

A macroeconomic modelling coursework project using Dynare to replicate and analyse a published model, with a focus on model implementation and the interpretation of impulse responses.

### Swiss GDP Forecasting — Technical Report

A group project comparing autoregressive and ARDL approaches to forecasting Swiss GDP growth, including the role of foreign economic activity. The technical report presents the data, econometric methodology and forecast evaluation in R.

### Swiss GDP Forecasting — Non-Technical Report

A companion report presenting the motivation, approach and main findings of the Swiss GDP forecasting project for a non-specialist audience.

*The two Swiss GDP forecasting reports describe the same group project.*
